# CitiScan web app

Next.js app for CitiScan: live map, trip planner and demo modes. See the [main README](../README.md) for how the
predictions work and how they were validated.

```bash
npm install
npm run dev   # http://localhost:3000
```

`data/flow_table.json`, `data/backtest.json` and `data/replays.json` are generated by the scripts in `../pipeline/`.
